# 00 — Como estudar neste repositório

O agente trabalha em dois modos:

- `LEARNING MODE`: você tenta, prevê, testa e explica;
- `ENGINEERING MODE`: o agente implementa diretamente quando você pedir.

Comece com `/session` e depois `/next`. Para código desconhecido use `/read`;
para uma falha use `/debug`; para uma tarefa nova use `/implement` ou
`/independent`.

O painel em `index.html` e `style.css` serve para acompanhar a trilha. Você não
precisa estudar a implementação visual para avançar na trilha principal.
