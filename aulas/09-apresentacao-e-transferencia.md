# 09 — Apresentação e transferência

Use `docs/learning/PRESENTATION_PREP.md` para explicar o projeto sem ler o
código. Depois escolha um domínio diferente, como uma API de clima, e
transfira o raciocínio de timeout, normalização, deduplicação e upsert.

O objetivo não é repetir frases do NASA CME: é reconhecer a mesma estrutura em
um problema novo.
