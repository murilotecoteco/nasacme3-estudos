# Sistema de aprendizagem

Esta pasta é a fonte de orientação do ambiente. A ordem recomendada é:

1. `PROJECT_AUDIT.md` — o que existe e quais são os limites;
2. `ROADMAP.md` — sequência técnica e pedagógica;
3. `COMPETENCY_MATRIX.md` — como o domínio será evidenciado;
4. `BACKLOG.md` — tarefas executáveis;
5. `IMPLEMENTATION_PLAN.md` — como manter o ambiente;
6. `COMMIT_RULES.md` — como registrar mudanças;
7. `PRESENTATION_PREP.md` — preparação para a banca.

Os prompts em `.github/prompts/` apontam para essa estrutura. O Codex usa
`AGENTS.md`; o Copilot usa `.github/copilot-instructions.md`.
