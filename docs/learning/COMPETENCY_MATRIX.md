# Matriz de competências

| Competência | Inicial | Em desenvolvimento | Evidência de domínio |
|---|---|---|---|
| HTTP/API | identifica URL e JSON | explica status, timeout e retry | cria teste para falhas e escolhe estratégia |
| Python | lê funções simples | implementa normalizador | divide responsabilidades e justifica interfaces |
| Dados | transforma um registro | remove duplicatas e cria lotes | preserva invariantes em casos extremos |
| Testes | executa testes | escreve casos normais e inválidos | antecipa falhas e testa contratos |
| SQL | identifica tabelas | explica UNIQUE e índices | justifica upsert, RLS e GRANTs |
| Segurança | reconhece secret | separa chave pública/privada | encontra exposição ou policy permissiva |
| CI/CD | lê workflow | altera um job com segurança | diagnostica falha real do Actions |
| Arquitetura | descreve fluxo | separa camadas | compara alternativas e trade-offs |
| Debugging | relata erro | formula hipótese | escolhe experimento mínimo e prova a causa |
| Comunicação | repete termos | explica com exemplo | responde perguntas novas da banca |

O nível só muda com evidência: código do estudante, teste criado, explicação,
debugging ou transferência. Velocidade e confiança declarada não bastam.
