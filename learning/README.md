# Memória de aprendizagem

Esta pasta guarda apenas o progresso específico do NASACME3 Estudos. Os
registros devem ser curtos, datados e baseados em evidências reais.

- `progress.md`: estado das tarefas;
- `concepts.md`: entendimento durável;
- `mistakes.md`: bugs e modelos mentais corrigidos;
- `questions.md`: dúvidas ainda abertas;
- `review.md`: perguntas de recuperação;
- `sessions/`: uma nota por sessão significativa;
- `assessments/`: avaliações práticas;
- `challenges/`: desafios e transferências.

Conceitos duráveis que servem a outros projetos também podem ser registrados
no diário compartilhado configurado pelo ambiente, sem duplicar todo o
histórico local.
